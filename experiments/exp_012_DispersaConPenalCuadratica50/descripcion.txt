Experimento: exp_012_DispersaConPenalCuadratica50
==============================================

Objetivo:
---------
Versión mejorada de exp_011 con coeficiente de penalización aumentado a -50.
Mantener la penalización dispersa cuadrática final, pero con escalado más fuerte
para que realmente desincentive el uso frecuente de C.

Configuración de recompensa:
----------------------------
Per-step (pasos intermedios):
  - reward = 0.0

Al final del episodio (por truncación o depleción):
  1. Recompensa de balance de habitaciones:
     - Se calcula p_i = visitas_i / suma(visitas_habitaciones) para i ∈ {Hab1, Hab2, Hab3}
     - desbalanceo = sum((1/3 - p_i)^2)
     - max_desbalanceo = (3-1)/3 = 2/3
     - reward_hab = 10 * ((max_desbalanceo - desbalanceo) / max_desbalanceo)
     - Rango: [0, 10]

  2. Penalización cuadrática de C (ESCALADO MEJORADO):
     - p_C = visitas_C / suma(todas_visitas)
     - penalty_C = -50 * p_C^2  [CAMBIO: de -10 a -50]
     - Rango: [-50, 0]

  3. Recompensa final:
     - reward_final = reward_hab + penalty_C
     - Rango teórico: [-50, 10]

Depleción de batería:
  - Si se agota la batería en un paso: reward = -10.0, terminated = True

Razonamiento:
-----------
- Penalización cuadrática de C con coeficiente -50: incentiva minimizar el uso de C de forma más agresiva.
  Baja frecuencia (e.g., p_C=0.1) → penalty ≈ -0.5
  Media frecuencia (e.g., p_C=0.2) → penalty ≈ -2.0
  Alta frecuencia (e.g., p_C=0.5) → penalty ≈ -12.5
  
- Esto hace la penalización COMPETITIVA con reward_hab, no insignificante.
- Con este escalado, ir a C con frecuencia media (20%) cuesta 2 puntos de reward,
  haciéndolo realmente importante en el balance de objetivos.

Diferencia con exp_011:
-----------------------
- exp_011: penalty_C = -10 * p_C^2 (demasiado débil)
- exp_012: penalty_C = -50 * p_C^2 (escalado mejorado, más competitivo)

Parámetros en robot_env.py:
---------------------------
- ROOM_NODES = ['Hab1', 'Hab2', 'Hab3']
- ALL_NODES = ['Hab1', 'Hab2', 'Hab3', 'C']
- _max_steps = 500 (configurable en reset())
- Escala de penalización C: 50 (5x más fuerte que exp_011)
- C_PENALTY_COEFF = 50 (constante configurable)
