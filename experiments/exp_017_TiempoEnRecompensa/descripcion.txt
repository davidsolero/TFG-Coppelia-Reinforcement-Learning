Experimento: exp_017_TiempoEnRecompensa
=======================================

Objetivo:
---------
Evaluar si, además de aportar contexto temporal en la observación, introducir una
Observacion: [nodo(0-3), bateria(0-100), vis1, vis2, vis3, vis_c, tiempo_ep(0-1)].
pequeña presión temporal en la recompensa ayuda al agente a reducir el tiempo de
cobertura sin comprometer la seguridad energética ni el balance entre habitaciones.

Este experimento continúa exp_016 y funciona como la segunda parte de la ablación:
- exp_016 responde a si el tiempo en la observación ya cambia el comportamiento.
- exp_017 responde a si, además, un coste temporal suave mejora la eficiencia.

Cambio principal respecto a exp_016:
------------------------------------
- Se mantiene `tiempo_ep` en la observación.
- Se añade una penalización temporal pequeña por paso no terminal en la recompensa.
- No se modifica la acción ni la estructura general del entorno.

Configuración de recompensa:
---------------------------
- Recompensa temporal por paso no terminal: `-0.02`.
- Penalización por batería agotada: `-10.0` y fin de episodio.
- Recompensa final al truncar por `max_steps`:
  - `reward_final = reward_hab + penalty_C`
  - `reward_hab` está en `[0, 10]` y mide lo uniforme que es la visita a Hab1, Hab2 y Hab3.
  - `penalty_C = -50 * p_C^2`, donde `p_C = visitas_C / (visitas_Hab1 + visitas_Hab2 + visitas_Hab3 + visitas_C)`.
- Las visitas se acumulan durante el episodio, pero solo la recompensa final usa esos contadores.

Calculo de recompensa (step)
---------------------------
if final_state['depleted']:
  reward = -10.0
elif self._numstepsinepisode >= self._max_steps:
  # Truncamiento: recompensa dispersa final basada en balance de habitaciones y penalizacion por C
  visits = np.array([
    self._visit_counts['Hab1'],
    self._visit_counts['Hab2'],
    self._visit_counts['Hab3'],
  ], dtype=np.float32)
  p = visits / np.sum(visits) if np.sum(visits) > 0 else np.array([0.0, 0.0, 0.0], dtype=np.float32)
  desbalanceo = np.sum((1.0/3.0 - p) ** 2)
  reward_hab = 10.0 * ((2.0/3.0 - desbalanceo) / (2.0/3.0))

  all_visits = float(sum(self._visit_counts[node] for node in ALL_NODES))
  if all_visits <= 0.0:
    penalty_C = 0.0
  else:
    p_C = float(self._visit_counts['C']) / all_visits
    penalty_C = -C_PENALTY_COEFF * (p_C ** 2)  # coeficiente = 50 en este experimento

  reward = reward_hab + penalty_C
else:
  # Paso intermedio no terminal: pequeña penalización temporal
  # Nota: los contadores `self._visit_counts` se actualizan en el momento
  # en que la acción se ejecuta (no dentro del cálculo de recompensa).
  reward = -TEMPORAL_STEP_PENALTY  # -0.02 por paso

Hipótesis:
----------
- El agente debería tender a completar la cobertura en menos pasos.
- La penalización temporal puede reducir esperas y paradas innecesarias.
- Si el coste es demasiado alto, puede empeorar el balance o aumentar el riesgo energético.

Criterio de diseño:
-------------------
- La penalización debe ser pequeña para no dominar la recompensa principal.
- El objetivo no es hacer speedrun puro, sino medir si la presión temporal mejora la
  eficiencia manteniendo full coverage, batería estable y patrulla balanceada.

Notas:
------
- Igual que en exp_016, el cambio de observación obliga a entrenar desde cero.
- Este experimento sirve para comparar tiempo como contexto frente a tiempo como incentivo.
- Si la mejora en full_coverage_step no viene acompañada de estabilidad y seguridad,
  el ajuste temporal no merece endurecerse más.
